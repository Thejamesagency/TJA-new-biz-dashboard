Both sheets need a published CSV link: in Google Sheets open the tab → File → Share → Publish to web → pick that sheet + Comma-separated values (.csv) → copy the link. Publishing makes the CSV readable by anyone with the link (no sign-in), which is what lets this page fetch it. If you'd rather not publish, paste the CSV text below instead — same parser either way.

1 · Emma's dynamic forecast (P&L)

Row labels must contain "Required NB (Sales Goal)" / "New Business Pipeline" per category — the parser matches the labels visible in the P&L and reads the 12 month columns.

2 · New-biz pipeline report

Matched columns (synonyms OK): Company / Opportunity Name, Sale Amount, Probability, Forecasted Close Date, Months, Lead Stage. Category is read from the opportunity name (“… - Retainer” → retainer, else project). 15. Hold rows are parked in the Holds list; dead / lost rows are skipped. To refresh: select the pipeline tab in the sheet → copy → paste below, or publish just that tab as CSV and fetch it. The page also ships a baked snapshot you can reset to.
