Add a file

Project files live in this repo under /projects/ and are served by GitHub Pages. To add a new one, paste the HTML into a Claude Code conversation and ask Claude to add it. Claude will: 
1. Write the HTML to /projects/<kebab-name>.html
2. Append an entry to /projects-manifest.json
3. git commit + push
~30 seconds later it appears on this page automatically. After that you can rename it, move it between folders, or archive it right here — all instant, no commit needed.

Example prompt: 
"Add this HTML as a project file called Acme Q3 Proposal. [paste HTML]"
